## 📌 作業工程の概要と構造分析

本動画では、キャラクターモデリングの難所である「立体感のある前髪・横髪・後頭部・ツインテール・エルフ耳・イヤリング」を、破綻なく綺麗な四角面トポロジーで組み上げるプロの手順が解説されています。

---

### 1. 前髪のベース作成と毛束分割 (00:01 - 02:45)
* **頭部からの複製分離**:
  - 顔メッシュの頭頂〜額の面を選択し、`Shift + D` で複製 → `P` で「選択を分離」。
  - 肌マテリアルを削除し、`S` キーでわずかに拡大（頭皮より一回り大きくして重なりを確保）。
* **非対称・分け目の成形**:
  - ミラーモディファイアを一度「適用」して実メッシュ化。
  - シームをクリアし、額のくぼみを `Alt + S`（法線膨張）でふっくら丸く均一化。
  - 片側半分を削除し、頂点・エッジを `G + X` や `G + G`（頂点スライド）で下絵のセンター分け・毛束ラインに合わせて配置。
* **モディファイア順序の妙**:
  - 再度オートミラーを適用。通常はミラーが最上位だが、**あえてサブディビジョンの下にミラーを置く**ことで、つむじ・分け目に完全な平坦化ではなく「自然な割れ目の陰影」を作る。
  - ソリッド化（Solidify）モディファイアを追加し、前髪全体の厚みを調整。

---

### 2. 横髪（サイドヘア）の押し出しと毛束の枝分かれ (02:45 - 07:18)
* **前髪からの連続複製**:
  - 前髪の外側エッジを選択し、`Shift + D` で複製 → `P` で分離。
  - `E` で下方向に押し出し、長さを `G + Z` で伸ばす。`Ctrl + R` でループカットを入れて毛先を `S` で絞る。
* **★ソリッド化モディファイアを使わない理由**:
  - サイド髪ではソリッド化を削除し、**メッシュ全選択から `E`（押し出し）で手動で厚みをつける**。
  - *理由*:
    1. 側面にポリゴン面が存在する方が、横から毛束を枝分かれ（押し出し）させやすい。
    2. 毛先を尖らせる際、四角面トポロジーが維持されるためループカットが綺麗に通る。
* **小毛束の追加（枝分かれ）**:
  - `Ctrl + R` で側面にループを入れ、面を選択して `E`（押し出し）＋ `S`（縮小）＋ `R`（回転）で小毛束を作る。
* **頭頂部の自然な馴染ませ**:
  - ミラーの「クリッピング（Clipping）」を外し、頭頂部中央を `G + X` であえてわずかに離して、頭皮に自然に溶け込ませる。

---

### 3. 後ろ髪（後頭部）のボリュームアップ (07:18 - 09:44)
* **後頭部面の複製**:
  - 顔メッシュの後頭部を選択し、`Shift + D` で複製 → `P` で分離 → `S` で少し拡大。
* **ちびキャラの黄金比率（頭でっかちボリューム）**:
  - 前髪・横髪・後ろ髪それぞれの頭頂部頂点を選択し、`G + Z` で上へ大きく持ち上げる。
  - *意図*: 頭頂部にボリュームを足すことで、ちびキャラ特有の愛らしいシルエットを作る。
* **丸い後頭部と襟足の密着**:
  - 後頭部下部〜中央を `Alt + S`（法線膨張）でふっくら丸く膨らませる（襟足から浮かない範囲で調整）。

---

### 4. ツインテールのモデリング (09:44 - 14:48)
* **立方体からの押し出しカーブ（重要テクニック）**:
  - 立方体を追加し、上下の面を削除して筒状にする。
  - 単なる四角柱にループカットを入れるだけだとX軸に平行な直線になって曲がらない。
  - **開口ループを選択 → `R + Y` で回転 → `E` で押し出し → `R + Y` で回転…** と少しずつ角度をつけていくことで、滑らかに湾曲する美しい毛束の背骨を作る。
* **斜め配置（45度傾き）**:
  - ツインテールの結び目を真横ではなく、上から見て45度（`R + Z`）後方に傾けて後頭部に沿わせる。
* **先細りとタプンとした丸み**:
  - 毛先に向かってプロポーショナル編集で `S` 縮小。中間部分を `G + X` で外側に膨らませて、ふんわりとした柔らかさを出す。
* **★プロの陰影エッジ出し（クリース効果）**:
  - 髪の角の稜線のすぐ隣に、**近接したループカット（サポートループ）を1本追加する**。
  - これにより、サブディビジョンをかけても稜線がボケず、パキッとしたハイライトと影が生まれて単調さが消える。

---

### 5. 耳（エルフ耳）とイヤリングの作成 (14:48 - 16:31)
* **顔からの耳の押し出し**:
  - 顔メッシュの側頭部面を選択し、斜め上へ `G` で引き伸ばして尖ったエルフ耳を形成。
  - 前面に `I`（面の差し込み）→ `G + Y` で奥へ凹ませて耳の穴と軟骨を表現。
* **ドロップ型イヤリング**:
  - UV球（16×13）を追加し、上部頂点をプロポーショナル編集（シャープ）で `G + Z` で引き上げて「しずく型」にする。
  - マテリアル：ルビーレッド（赤色）、粗さ（Roughness）を極限まで下げ、伝播（Transmission）を上げて宝石ガラスの透明感を表現。
