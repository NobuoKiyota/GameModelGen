## 3. モデリング方針とトポロジー黄金律

### 核心方針: 「大ラフ（ブロックアウト）」の徹底
1. **極小頂点からの開始**:
   - 最初から厚みや細かい毛先を作らず、**1枚の板（四角面）や4面筒** から外形シルエットだけを合わせる。
2. **隣り合う房の段数同期（トポロジー整合）**:
   - **「隣り合う房同士の段の高さ（横エッジループのZ座標）を揃える」**。
   - 理由: シルエットが美しく整うだけでなく、将来のボーン入れ・ウェイトペイント（スキニング変形）での破綻を防止するため。
3. **モディファイアのスタック順**:
   - `Mirror`（最上段、Clipping=True） $\to$ `Subdivision Surface`（レベル1、ショートカット `Ctrl + 1`）。
   - **必ず Mirror を Subsurf の前に配置する**（正中線の裂け・不自然な凹みを防止）。

## 4. パーツ別詳細手順

### Part 1: 前髪の大ラフ（00:00〜09:05）
- **構造上の非対称性**:
  - 額中央の最前面の1房のみ **左右非対称**（Mirrorなし）。
  - その他のサイド前髪・横髪は **左右対称（Mirror適用）**。

#### (A) メイン前髪（非対称房）
1. `Shift + A` $\to$ メッシュ `Plane`（平面）を追加。
2. 編集モードで `R X 90` で正面（-Y）に向ける。
3. `G Z` で額の位置へ移動。おでこの曲面に沿って `E`（押し出し）で縦方向に伸ばす。
4. 形状: 上端を絞り、中央をやや広げ、毛先（下端）をキュッと狭める。
5. `Ctrl + 1` で `Subdivision Surface`（レベル1）を追加。
6. 毛先（下端エッジ）に `Shift + E` で **クリース = 1.0** を設定してシャープ化。
7. `Ctrl + R` で中央に縦ループを1本追加し、`Alt + S` で前方に膨らませて緩やかな丸みを持たせる。

#### (B) サイド前髪（対称房）
1. メイン房から `Shift + D` で横に複製。
2. **ピボットポイントの活用**:
   - ピボットポイントを「アクティブ要素（Active Element）」に変更。
   - 房の頭頂側（根元）の頂点を最後に選択（アクティブ化）し、`R R`（トラックボール回転）で根元を軸に自然な傾きで回転配置。
3. `P` $\to$ `Selection` で別オブジェクトに分離。
4. `Mirror` モディファイアを追加（Subsurfの上に配置、Clipping=True）。
5. 正中線に接する上部頂点を中心にスナップ結合し、中央エッジにクリースを付与。
6. **段数同期**:
   - メイン房の横エッジループの高さと、サイド房のエッジループの高さをほぼ一致させる。
7. 顔側面カバー房:
   - 再び `Shift + D` で側頭部へ複製。`S Y` で前後幅（厚み）を確保。
   - `Ctrl + R` でループを追加し、`Alt + S` でふっくらと丸みをつける。
8. **前後レイヤー関係（重なり順）**:
   - 下絵の前後関係を確認。手前に来る房の頂点を `Alt + S` または `G Y` で外側/手前に引き出し、奥の房の上に綺麗に乗せる。

### Part 2: 後ろ髪の大ラフ（09:05〜16:24）
- **原型**: `Cylinder`（円柱、頂点数 **12**）から作成。

1. `Shift + A` $\to$ メッシュ `Cylinder`（頂点数 **12**）を追加。
2. 編集モードで顔の前面側（前方の4面）を `X` $\to$ `Faces（面削除）` で削除（開口した半円筒にする）。
3. 頭頂部に `Ctrl + R` でループを追加し、一番上の面/辺を `S X`, `S Y` で絞って頭頂部を閉じる方向に縮小。
4. `Ctrl + 1` で `Subdivision Surface`（レベル1）を追加。
5. `Mirror` モディファイアを追加（Subsurfの上に配置）。正中線をクリッピングで結合。
6. 正中線エッジ列を選択し、`LoopTools: Relax`（リラックス）で滑らかに整流。
7. `Ctrl + R` で横ループを2〜3本追加し、`Alt + S` で後頭部の豊かな丸みを膨らませる。
8. **襟足・下端**:
   - 下端は逆に `Alt + S` で少し首筋に向けてすぼめる。
9. **横髪（サイド）との境界調整**:
   - 後ろ髪の前面エッジが、サイド前髪の内側（裏側）に自然に入り込むよう位置調整。
10. **耳の逃げ穴（重要）**:
    - 猫耳（または人間の耳）の付け根が入る位置を、プロポーショナル編集で少し後ろへ後退させ、空間を空けておく。
11. **生え際ディテール**:
    - 正中線付近に `Ctrl + R` でループを追加し、中央頂点に `Shift + E`（クリース）をかけて少し下げることで、自然なV字生え際を表現。

---

### Part 3: ツインテールの大ラフ（16:24〜20:55）
- **原型**: `Cube`（立方体）から作成。

1. `Shift + A` $\to$ メッシュ `Cube` を追加。
2. 上面と底面を `X` $\to$ `Faces` で削除（4面の四角筒にする）。
3. `S` で全体縮小、`S Z` で縦方向に伸ばす。
4. `Ctrl + R` で横ループを2本追加（計3〜4段の筒）。
5. 後ろ髪オブジェクトを選択し、`Ctrl + J` で結合（後ろ髪の Mirror + Subsurf をそのまま継承）。
6. **シルエットの形成**:
   - 根元（結び目）: `S` でキュッと極小に絞る。
   - 結び目直下: `Alt + S` で大きくボリューミーに膨らませる。
   - 毛先（下端）: `S` で小さくすぼめる。
7. **カーブ曲げ**:
   - プロポーショナル編集をONにして、全体をふんわりと外側〜下側へS字/C字にカールさせる。

---

### Part 4: 形状整流テクニック（全体共通）
- **頂点スムーズ（Vertex Smooth）の活用**:
  - メッシュの頂点が一部だけ飛び出したり凹んだりした場合、メッシュ $\to$ 頂点 $\to$ `頂点のスムーズ化（Smooth Vertices）` を適用。
  - トポロジーを乱さずに自然な曲率に均一化される。

## 5. Claude Code 向け実装設計チェックリスト

1. **メッシュとオブジェクト構成**:
   - `Hair_Front_Center`: 非対称のメイン前髪（Mirrorなし、Subsurf 1）。
   - `Hair_Main`: 対称パーツ（サイド前髪、横髪、後ろ髪、ツインテール）。Mirror（最上段）＋ Subsurf（レベル1）。
2. **段数管理の自動化/整合**:
   - 房ごとの横ループの Z 座標を揃える（例: 額上端、眉上、目の中央、頬、顎などの主要ラインにループを合わせる）。
3. **断面形状**:
   - 前髪・サイド髪: 薄い板（1面）に中央縦ループ＋`Alt + S` 膨らみ。
   - ツインテール: 4面筒（Cubeの上下抜き）にループ追加＋膨らみ。
