# Antigravity への依頼: 髪モデリングの「先行学習メモ」の作り方

**依頼元**: Claude Code / **日付**: 2026-09-25 / **対象**: ふさこ氏の動画（特に 03 髪の大ラフ・09 前髪/横髪の作り込み・10 後ろ髪＆ツインテール・15 ヘアアクセ・22 髪のスキニング・24 髪のUV）

## 目的
Claude Code は、動画の内容を「数値や条件として実装・検証できる形」で受け取ると、生成・検証を正確に進められる。
これまでの手順書・スクショ（`.agents/handoffs/2026-09-24_fusako_*_steps.md`、`docs/fusako_NN_*_screenshots/`）は操作の説明としては十分だが、
**実装に必要な数値・合格条件・自動化の可否**が不足していた（髪 H01/H02 で実際にやり直しが多発した）。
下記の項目を、既存の手順書に**追記する形**か、別mdで足してほしい。

## 背景（Claude Code が髪で実際につまずいた点）
- 房を「ひし形断面×多頂点」で自動生成 → 見た目が悪い。人間の手作りは「幅広で薄い長方形断面（4頂点）×6〜7駅の箱＋Subdivision(1)」（24〜40頂点/房）で、はるかに良かった
- 「細いリボンを離して並べる」「隙間のない1枚の面」のどちらも却下（実際は、丸みのある房が重なって隙間なし）
- 頭頂の禿げ、房の隙間、毛先の形（尖る/丸い）、ウェーブ感の不足
- 手作りメッシュに、拡大縮小(0.015等)・位置オフセット・モディファイア順(Subdivision→Mirror)のずれが残っていた
→ **どれも、事前に数値・条件が分かっていれば防げた／数値ゲートにできた**

## 必要な項目（優先度順）

### 1. 各パーツの完成形の構造（最重要）
1房（またはパーツ）ごとに:
- 頂点数・面数、**断面の頂点数**、駅（断面の並び）の数、縦ループ数
- モディファイアの種類・順序・レベル（例: Mirror → Subdivision(1)。Clippingの有無）
- オブジェクトの分け方・名前・コレクション、拡大縮小・回転の適用状態
- 前髪の中央の房のみ非対称、など「Mirrorを使う/使わない」の区別

### 2. 頭に対する比率（相対値）
動画の画面上のピクセル値ではなく、**頭（顔）のサイズを基準にした比率**で:
- 房の幅・長さ・厚み、先端のすぼめ方（根元に対する先端の幅/厚みの割合）
- 隣の房との重なり量、頭皮からの浮かせ量（Alt+S の量）
- 段の高さ（横ループのZ）を揃える位置（額の上端・眉上・目・頬・顎など、頭の何%の高さか）
- 動画の髪型と、今のキャラの髪型（**茶色の肩までのウェーブボブ＋一直線気味の前髪、ツインテール無し**、下絵は `textures/human/chibi_hair_ref_{front,side,45}.png`）で、
  寸法がそのまま使えない所は、その旨を注記

### 3. 工程ごとの合格条件（機械的に確認できる形）
例: 「隣接する房の段の高さが揃っている」「T字ポリゴン（1辺に3面）が無い」「非多様体が無い」
「N-gon が無い」「面の向きが外向き」「拡大縮小・回転が適用済み」「Mirrorの正中線が結合されている」
→ できるだけ「数を数える／範囲を測る」で判定できる書き方にする

### 4. 操作の理由
Subsurfの縮み対策、ウェイトペイントでの破綻防止、MToon透過（前髪から眉が透ける演出）、Unity/VRMでの制約など。
他の髪型に応用する時の判断材料にする。

### 5. 失敗例とその直し方
動画に出てくる不具合（T字ポリゴン、非多様体、隙間、スカスカ、Subsurfで潰れる 等）と、動画内の直し方。

### 6. 自動化できる／人間の判断が要る の区別
各工程に次のラベルを付ける:
- **数値で決まる**（Claude Code が生成・検証できる）
- **形の好みで決まる**（ウェーブの付け方、房の流れ、毛先の割れ方 など。人間の手作りを基準にする）

### 7. 後工程からの逆算
動画19〜27（リギング・スキニング・UV）が、髪に求める条件（房の段数の揃え方、UVの切り方、スキニングしやすい分け方、
ボーンを入れる前に髪で満たしておくべきこと）。先に髪を作る段階で満たしておけば手戻りが減る。

## 形式のお願い
- 表形式。**1行＝1操作**。列: `時刻｜操作｜目的｜結果の数値（頂点数・比率）｜確認方法｜自動化可否`
- 可能なら、同じ視点の「操作前／操作後」のスクショを並べた画像（ワイヤー表示のもの）
- 既存の手順書と重複する内容は省略してよい。数値・条件・ラベルの追記が主
