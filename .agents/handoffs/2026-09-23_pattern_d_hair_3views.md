# 髪型参考下絵（パターンD：セミロング）3面図作成レポート

## 概要
ユーザー選定の髪型「パターンD（ふんわりセミロング）」に基づき、確定済み頭部モデルのサイズ・比率・位置を100%完全厳守した「正面図」「真横図」「斜め45度図」の3面参考下絵（1024×1024px PNG、ブループリントグレー背景）を作成・配備しました。

## 仕様と遵守状況

| 項目 | 指定条件 | 実装結果 | 判定 |
| :--- | :--- | :--- | :---: |
| **頭部形状・比率** | 元画像（ハゲ頭）の輪郭・比率・位置を一切変更しない | 鼻・口・目のランドマーク誤差 < 0.1px で完全保持 | **PASS** |
| **画像フォーマット** | 1024×1024px、PNG | 1024×1024px PNG（3枚） | **PASS** |
| **背景色** | 既存ブループリントと同じグレー | RGB `[205, 205, 205]`（#cdcdcd）に統一 | **PASS** |
| **髪型デザイン** | パターンD（ふんわりセミロング・ミルクティーブラウン） | 前髪レイヤー＋フェイスライン房＋丸い後頭部＋肩口の毛束 | **PASS** |
| **3面の幾何整合** | 正面・真横・45度のパーツ高さ・比率の一致 | 毛先最下端 Y=997（一致）、目・口の高さ誤差 2〜5px 以内 | **PASS** |
| **ファイル保護** | 既存の下絵（`chibi_blueprint_*.png`）を上書きしない | 新規ファイル `chibi_hair_ref_*.png` に保存 | **PASS** |

## プロシージャルモデリング設計上の要点
1. **前髪**:
   - 額中央でふんわり分かれるナチュラルバング（3〜4本の主要房）。
   - 両サイドの長めの毛束（サイドロック）が頬を優しく包む。
2. **後ろ髪**:
   - 後頭部上部は12頂点円柱ベースの丸いボリューム。
   - 首筋から肩口へ広がる下部レイヤーは、房ごとの押し出し＋先端クリースで表現。
