## 3. フェーズ別詳細操作手順

### Phase 1: 目のモデリング（00:00〜02:36）
- **目的**: 瞳（黒目）メッシュの作成と眼窩への配置。
- **操作列**:
  1. `Shift + A` で `UV球`（UV Sphere）を新規追加。
  2. `R X 90` で球の前面（極点）を前方向（-Y）に向ける。
  3. 編集モードで一番手前の中心頂点を選択。
  4. `Ctrl + +`（テンキー）を数回押して、瞳の大きさ（お椀型・ドーム型）まで選択範囲を拡大。
  5. `Ctrl + I` で選択を反転し、`X` $\to$ `Vertices（頂点削除）` $\to$ 前面の円盤状メッシュのみ残す。
  6. **凹面化（逆ドーム形状）**:
     - プロポーショナル編集をON（フォールオフ形状: `スフィア / Sphere`）。
     - `G Y` で中心を奥方向へ引っ込める（アニメセルルック特有の「凹み瞳」により、視線追従効果が生まれる）。
  7. **スケール・比率調整**:
     - オブジェクトモードで `S` で顔のスケールに合わせて縮小。
     - `S X` で横幅を縮め、縦長のアニメ瞳形状にする。
  8. **眼窩への角度フィッティング**:
     - 下絵の眼窩位置へ `G` 移動。
     - 上面ビュー（テンキー7）から見ながら、少し外側を向くように回転（Z軸回転）。
     - 側面ビュー（テンキー3）から見ながら、少し下側を向くように回転（X軸回転）。
  9. **ミラー設定**:
     - `Mirror` モディファイアを追加。
     - ミラーオブジェクト（Mirror Object）に「顔（Face）」を指定（顔の中心軸で対称化）。
  10. **重要特記事項**:
      - **目オブジェクトには Subdivision Surface モディファイアは適用しない**（動画 31:40 付近で明言）。
      - 右クリック $\to$ `Shade Smooth`（スムーズシェード）のみ適用。

### Phase 2: まつ毛のモデリング（02:36〜12:01）
- **目的**: 目の上縁に沿った立体的なダイヤモンド型断面の上まつ毛、および細い房まつ毛の作成。
- **操作列**:
  1. **ベースラインの抽出**:
     - 顔オブジェクトの編集モードで、目の上縁（アイライン）に該当する辺ループを選択。
     - `Shift + D` で複製、`Esc` でその場確定。
     - `P` $\to$ `Selection（選択物を分離）` で別オブジェクトに分離。
  2. **ダイヤモンド型（ひし形）断面の押し出し**:
     - 分離したまつ毛オブジェクトを選択し編集モードへ。
     - 外側ライン作成: `E S`（押し出し拡大）で外側へ広げる。顔に埋まる部分は `G Y` で手前に引き出す。
     - 内側ライン作成: 外側ラインの辺を選択し、`E S`（押し出し縮小）で内側の縁を作る。
     - 端の穴埋め: 目頭・目尻の開放部を `F` キーで面張り（四角形/三角形）。
     - **断面の立体化**:
       - `Ctrl + R` でまつ毛の中央に長手方向のループカットを1本追加。
       - `Alt + S`（法線方向に収縮/膨張）で外側に膨らませる $\to$ 断面がひし形（外に山ができる）になる。
       - 膨らませた中央稜線（ループ）を選択し、`Shift + E` で **クリース = 1.0** を設定。
  3. **モディファイアと端の処理**:
     - `Subdivision Surface`（レベル2）を追加。
     - 目頭・目尻の端の頂点を `S` で極小に絞る（穴がほぼ見えない状態、または面張り）。
     - 目尻のシルエットを下絵の跳ね上げに合わせて頂点移動。
  4. **細いまつ毛（房/ぴょこ毛）の作成**:
     - メインまつ毛の辺を `Shift + D` で複製、クリースを解除。
     - `E Y` で前に押し出し、`S` で縮小、`Ctrl + R` でループ追加して `G Z` でカールさせる。
     - 両端を `F` で閉じ、輪郭エッジにクリースを付与。
     - この細いまつ毛をメインまつ毛の裏側から斜めに突き刺すように配置（交差配置）。
     - `L`（リンク選択） $\to$ `Shift + D` で複製し、下絵に合わせて複数配置。
  5. **法線の反転修正**:
     - ビューポートオーバーレイで「Face Orientation（面の向き）」をON。裏返り（赤色）を確認。
     - `A` 全選択 $\to$ `Alt + N` $\to$ `Flip（反転）` で表向き（青色）に修正。
     - `Shade Auto Smooth`（自動スムーズ）を設定。

### Phase 3: まゆげ・二重線のモデリング（12:01〜13:50）
- **操作列**:
  1. **眉毛**:
     - 顔オブジェクトの額/眉付近の辺を選択し、`Shift + D` で複製。
     - `E` で眉尻へ向けて段階的に押し出し。
     - 顔の曲面にふんわり沿うように配置（埋まらない程度に微小手前）。
  2. **二重線（アイリッド）**:
     - 同様に目の上の辺を `Shift + D` で複製し、目の上の二重ラインへ配置。
     - 下から見上げて緩やかな円弧状にカーブさせる。

---

### Phase 4: UV展開（13:50〜17:38）
- **操作列**:
  1. **シーム（Mark Seam）の配置**:
     - 目の穴の境界エッジ（`Alt + Click` $\to$ `Ctrl + E` $\to$ `Mark Seam`）
     - 口の穴の境界エッジ（`Ctrl + E` $\to$ `Mark Seam`）
     - 顔の前面と後面（側頭部〜首）を分割するシーム
     - 首の付け根のシーム
  2. **展開**:
     - 顔: `A` 全選択 $\to$ `U` $\to$ `Unwrap`
     - まつ毛: 正面から見て `U` $\to$ `Project from View（ビューから投影）`
     - 目: スケール適用（`Ctrl + A` $\to$ `Scale`）後に `U` $\to$ `Unwrap`
  3. **UVスペースのレイアウト**:
     - 単一テクスチャ（2048×2048）に顔前面、まつ毛、目、眉毛を配置。

---

### Phase 5: テクスチャペイント＆ハイライト二重メッシュ構造（17:38〜32:53）
- **操作列**:
  1. **マテリアル共有**:
     - まつ毛、目、顔を選択し、`Ctrl + L` $\to$ `Link Materials` で同一マテリアルを割り当て。
  2. **ハイライト板（二重メッシュ構造・超重要）**:
     - 目のメッシュを編集モードで `A` 全選択。
     - `Shift + D` で複製し、直後に `Y` で**わずかに手前（-Y方向）にオフセット配置**。
     - UVエディタでこのハイライト用メッシュのUV島を別の空き領域に移動。
     - テクスチャペイントで、ハイライト領域を一度アルファ消去（`Erase Alpha`）で透明化。
     - 透明な板の上に白色でハイライト（星や光点）を描画。
     - **利点**: 瞳テクスチャとハイライトが独立した深度を持ち、視線を動かしてもハイライトが浮き上がって立体的に見える。
  3. **口元・まつ毛の最終微調整**:
     - 鼻〜顎の傾斜ラインに沿って口を斜めに微小移動。
     - `S X` で口角幅を狭めてデフォルメオメガ口（ω）に整形。
     - まつ毛の先端に `V`（リップ切り裂き）を入れて二股に分割。
  4. **オブジェクト結合・整理**:
     - まつ毛と顔を選択し、`Ctrl + J` で結合（オブジェクト名: `Face`）。
     - 目（Eye）は **Subsurf を使わないため結合せず、独立オブジェクト** として維持。
     - 参考画像や下絵を `Reference` コレクションに移動して整理。

## 4. Claude Code 向け実装上の要点（チェックリスト）

1. **トポロジーとモディファイアの使い分け**:
   - `Face`: Subsurf（レベル2）あり、Mirror（Clipping=True）あり。まつ毛・眉・二重は最終的にこれに結合可能。
   - `Eye`: **Subsurf なし**。Mirror のみ（Mirror Object = Face）。
2. **目（瞳）の幾何形状**:
   - 平面ではなく「逆ドーム（凹面）」。中心が奥（+Y）、周縁が手前（-Y）。
   - 上面から見て外向き（Z回転）、側面から見て下向き（X回転）。
3. **ハイライトの二重メッシュ構造**:
   - 瞳メッシュの前面にわずかにオフセット（数ミリ〜1cm程度）された同一曲率のメッシュ。
4. **まつ毛の立体感**:
   - 平面ポリゴンではなく、ひし形（ダイヤモンド型）断面＋中央稜線クリース 1.0。
