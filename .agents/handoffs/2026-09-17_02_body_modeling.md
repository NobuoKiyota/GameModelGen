## 📌 作業工程の概要と構造分析

1. **顔からの首の押し出し (00:00 - 01:50)**
   - 顔底面の三角面対策：頂点選択から `Ctrl + Num+` で拡大選択
   - `I`（面の差し込み）で首の太さにインセット → `X`（面削除）で開口
   - 頂点を `G + X` で外に広げて真円化
   - `Alt + クリック` でループ選択 → `E + Z` で首をまっすぐ押し出し
   - `Ctrl + Num+` で首面を選択し `S` で太さ微調整

2. **立方体ベースの胴体作成 (01:50 - 03:40)**
   - 頭と体は別パーツ（作業性・非表示・軽量化）
   - `Shift + A` で立方体追加 → サブディビジョンサーフェス（1）追加
   - **【最重要テクニック】サブディビジョン（レベル1）をオブジェクトモードで確定（適用）する**
     - これにより、低ポリゴンで均一な四角面の球体ベース（キューブスフィア）が得られる
   - `S` 縮小、`G + Z` で首下に配置 → オートミラー（X軸）
   - 側面の2辺を `G + X` でくびれ（ウエスト）作成
   - 上部（肩・胸）を `G + X` で広げ、`G + Z` で上へ持ち上げる
   - 透過表示（`Alt + Z`）で側面から前側の頂点を `G + Y` で後退させ厚みを薄く

3. **胴体の立体感・S字カーブ形成 (03:40 - 05:15)**
   - ウエスト位置に `Ctrl + R` でループカット
   - **背中側の辺だけ選択して `G + Y` でくぼませる**（お腹はへこませない）
   - 股下の頂点を `G + Z` で下方に引き下げ
   - サブディビジョンサーフェス（レベル2）追加、スムーズシェード適用
   - `S + Y`（厚み）と `S + Z`（高さ）で体格を再調整
   - 胸の位置に `Ctrl + R` でループカット → **`Alt + S`（法線収縮・膨張）でふっくら丸みを持たせる**
   - 股下を `G + Z` で下げ、`G + Y` で内側へ
   - `Shift + D` で胴体のバックアップ作成

4. **腕の押し出し（Tポーズ） (05:15 - 06:40)**
   - 側面ビューで腕の位置確認
   - 側面の1面を選択 → `I` で面差し込み（丸に近い形状に）
   - 正面ビュー（`1`）で `E` キーで横に押し出し
   - 今後の服作り・ボーンウェイト付けのため「Tポーズ（水平）」にする
   - デフォルメ感：手先を `S` で拡大して少し大きめに

5. **足の生やし方と整流 (06:40 - 08:30)**
   - 胴体底面の2面を選択 → `X` で面削除
   - 開口エッジを `Alt + クリック` でループ選択 → `F` で1つの面に張り替え
   - `I` で内側に面を差し込む（綺麗な足の断面ループを作成）
   - 正面ビューで `E + Z` で下方向に押し出し
   - 太もも上部に `Ctrl + R` でループカット追加 → 側面を選択して **`Alt + S` で外側に膨らませる**
   - 足底の歪み解消：頂点を `G + G`（頂点スライド）で水平に整える
   - `S` で足先を縮小、`G + Z` で長さ調整、`G + X` で外側に開く（ハの字）

6. **側面プロファイルとお尻の仕上げ (08:30 - 09:40)**
   - 側面ビューで足底を `G + Y` でやや前方に移動
   - 太もも裏の辺を `G + Y` で厚み調整
   - 脚中央に `Ctrl + R` でループカット → 膨らみすぎを `G + Y` で凹ませる
   - **お尻の丸み**：頂点を `G + Z` で下げて丸みを作り、垂れ防止でヒップトップを `G + Z` で引き上げ
   - 歪んだエッジの流れを `G + G`（頂点スライド）で綺麗に整流
