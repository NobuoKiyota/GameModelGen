## 0. 全体構造とトポロジー設計思想

* **モデリング方式**: サークル（頂点数8）による「目のアイホール」から開始し、顔面マスク $\to$ フェイスライン $\to$ 頭頂・後頭部 $\to$ 首シリンダー結合 $\to$ 眼窩・口腔ソケット形成へと展開する王道のアニメ顔トポロジー。
* **基本設定**:
  * ミラー（X軸）＋クリッピングON（常に左半分を作成）
  * 初期は平行投影（Ortho）、後半で `Numpad 5`（Perspective, Focal Length = 80mm）で立体感確認
  * モディファイア: `Mirror`（最上位） $\to$ `Subdivision Surface`（レベル2）
  * 基本シェーディング: オートスムーズ 180° + クリース（`Shift + E`）/ マークシャープ（`Ctrl + E`）

## 1. 詳細操作ステップ一覧 (タイムスタンプ順)

### 【フェーズ1: 目と口の基本ループ形成】 (05:30 〜 09:30)

#### ステップ 2-1: 目の基礎ループ（サークル）配置 [05:30〜07:45]
1. `Shift + A` $\to$ **メッシュ > 円（Circle）** を追加。
   * **頂点数（Vertices）**: **`8`**（超重要！多すぎず少なすぎない8角形）
2. `Tab` キーで編集モードに入る。
3. `R X 90` で円を正面（-Y方向）に向ける。
4. 正面ビュー（テンキー1）で下絵を見ながら `S`（縮小）、`G`（移動）で片目の輪郭に合わせる。
   * ピボットポイントは `.`（ピリオド） $\to$ 中点（Median Point）。
5. 上から見て（テンキー7）、目尻側の頂点を `G Y` で奥（+Y）へ下げる（顔の丸みに合わせた斜めアーチ）。
6. `Alt + 左クリック` で円の全8辺をループ選択。
7. **`E`（押し出し） $\to$ `S`（拡大）** で外側に一回り大きいループを作成（二重ループ＝アイライン/眼輪筋の帯ポリゴン）。
   * **頂点数**: 内側8頂点 + 外側8頂点 = 計16頂点（面数: 8枚の四角面）。
8. 側面ビュー（テンキー3）を見ながら、全体を `A` で選択し `G Y` で顔表面の深さに合わせる。
   * 目頭側は前（-Y）、目尻側は後頭部側（+Y）へ傾斜。

#### ステップ 2-2: 口のループとミラー設定 [07:49〜09:30]
1. 目の外側ループから頂点を1つ選び、`Shift + D` で口の位置へ複製。
2. `E`（押し出し）を連続して行い、下絵の唇の割れ目線に沿って「半分の口のループ（4頂点程度）」を作成。
3. **`Mirror` モディファイアを追加**。
   * 軸: `X`
   * **`Clipping`（クリッピング）: ON**（中心軸 X=0 で結合させるため必須）。
4. 中心軸の頂点を `G X` で内側へ動かし、X=0 でクリップ結合。
5. 側面ビュー（テンキー3）で口全体を `G Y` で前方に移動し、下絵の口元の斜め傾斜に合わせる。
6. 口のループを選択し、**`E`（押し出し） $\to$ `S`（拡大）** で外側へ口輪筋の帯を作成。
   * 外側ループも中心軸（X=0）でクリップ結合。
7. 側面から見て、外側ループを口の傾斜に沿って綺麗に整流。

---

### 【フェーズ2: 鼻筋・頬・フェイスラインの接続】 (09:34 〜 14:00)

#### ステップ 2-3: 鼻筋ラインの押し出し [09:34〜10:30]
1. 目の外側ループの「目頭上」の頂点を選択。
2. `E X` で中心（X=0）に向かって押し出し（クリッピングで中心吸着＝眉間・鼻根）。
3. 側面ビューを見ながら、鼻根（くぼみ）に `G Y` で合わせる。
4. 中心頂点から `E Z`（または `E`）で下方へ押し出し、鼻先（一番高い頂点） $\to$ 鼻下 $\to$ 口の外側ループ上端まで押し出し接続。
5. 側面ビューで鼻先の高さ・突き出し量を下絵に合わせる。

#### ステップ 2-4: 頬から顎先へのフェイスライン [10:32〜11:40]
1. 目の外側ループの下端（頬骨あたり）のエッジを選択。
2. `E` で下へ押し出し、`R` で少し回転させながら、顎先（X=0）まで2〜3回押し出し。
   * 最後の頂点は中心軸（X=0）でクリップ吸着。
3. 側面ビューで見ながら、このラインを「下絵の顎の輪郭・フェイスライン」にぴったり合わせる。
4. 正面ビューで頬のふくらみから顎先への輪郭カーブを整える。

#### ステップ 2-5: 頬・鼻・口の面張り（グリッド結合） [11:45〜13:40]
1. フェイスラインと口の外側ループの間に `Ctrl + R` でループカットを追加。
2. 対応する頂点同士を選んで `M` $\to$ `At Center`（中心にマージ）で接続。
   * （直前の操作を `Shift + R` でリピート）。
3. 鼻の先端から頬骨にかけて `Ctrl + R` でループを追加し、4頂点を選んで `F`（面貼り）で四角面を埋める。
4. くぼみすぎている頂点を、座標系を「ノーマル（Normal）」に切り替えたギズモで法線方向外側へ引き出し、滑らかな曲面にする。

---

### 【フェーズ3: こめかみ・額・頭部側面への展開】 (13:42 〜 17:50)

#### ステップ 2-6: フェイスラインの後方押し出し [13:42〜15:05]
1. 目の横から顎先までの外側エッジラインを `Ctrl + 左クリック`（最短経路選択）で一括選択。
2. **`E Y`** で後方（+Y方向）へ押し出し。
   * 下端は下絵の「首の付け根近く」まで持ってくる。
3. 顎下側・おでこ（額）側へ頂点を延長し、`F` で面を貼ってマスク状のシェルを広げる。
4. おでこのラインは上から見て（テンキー7）なだらかな半円カーブを描くように調整。

#### ステップ 2-7: サブディビジョン追加とエッジシャープ化 [15:07〜17:50]
1. **`Subdivision Surface` モディファイア（レベル2）** を追加。
2. 鼻先をツンと立たせるため、**`K`（ナイフツール）** で鼻先の周囲を三角/ひし形状に囲みカット（サポートループ）。
   * `G G`（頂点スライド）で鼻先近くに寄せる。
3. 顎先も `Ctrl + R` でループを1本追加し、`G G` で下端へ寄せて顎をシャープにする。
4. 口角の周囲の割りが足りない部分を選択し、右クリック $\to$ `Subdivide`（スムーズネス調整）。

---

### 【フェーズ4: 後頭部のモデリング】 (17:56 〜 22:15)

#### ステップ 2-8: 額から後頭部・首元への押し出し
1. 額の中心最上段のエッジを選択。
2. 側面ビュー（テンキー3）を見ながら、下絵の後頭部カーブに沿って `E`（押し出し） $\to$ `R`（回転）を繰り返しながら、頭頂 $\to$ 後頭部 $\to$ 盆の窪（首の付け根上）まで円弧状に押し出す。
3. 側面の開口部（こめかみ〜側頭部）の頂点を選び、`F` で四角面を順次貼って塞ぐ。
4. `Ctrl + R` で縦・横にループを追加し、**`Alt + S`（法線方向に膨張）** で頭部の丸みをふっくらと出す。
5. 顎下から首元へのラインも頂点同士を `M` $\to$ `At Last` でマージして塞ぐ。

---

### 【フェーズ5: 首の作成と頭部結合】 (22:16 〜 28:50)

#### ステップ 2-9: 首シリンダーの追加と頭部マージ
1. オブジェクトモードで `Shift + A` $\to$ **メッシュ > 円柱（Cylinder）** を追加。
   * **頂点数**: **`12`**
   * **キャップ（蓋）**: **なし（Nothing）**
2. `S` で縮小、`G Z` で首の位置へ配置。
3. 編集モードで首根元のループを `E` $\to$ `S` で外側にフレア状に広げる。
4. オブジェクトモードに戻り、Auto Mirror（または首の左半分を削除してMirror適用）。
5. 頭部メッシュと首メッシュを選択し、**`Ctrl + J` で1つのオブジェクトに結合**。
6. 編集モードで、頭部底面と首上端の対応する頂点間に `F` で面を貼り、ループカットを足しながら完全に穴を塞ぐ。
7. 顎のフェイスラインを際立たせるため、顎下エッジを `G G` で少し寄せる。
8. テンキー5で透視投影（Perspective, Focal Length = 80mm）に切り替え、頬の丸みを微調整。

---

### 【フェーズ6: 白目（眼窩ソケット）と口腔ソケット】 (28:52 〜 36:00)

#### ステップ 2-10: 白目（奥壁）の作成 [28:52〜33:15]
1. 目の開口部（初期サークル内側）の頂点数を確認。
   * 上3頂点、下4頂点など偏りがある場合は、上部にループを追加して**「上下同数（4対4）」**に揃える。
2. スカルプトモードに入り、「スライドリラックス（Slide Relax）」ブラシ（`Shift` 押しながら撫でる）で面の偏りを均等化。
3. 開口部エッジを `Alt + クリック` でループ選択。
4. **`E Y` で後方（奥）へ押し出し** $\to$ `S` で少し拡大。
5. `Shift + H` で他を非表示にし、奥の穴を `F`（面貼り）＋ `Ctrl + R`（中央分割） $\to$ `F` で完全に四角面で塞ぐ。
6. 中央部分を少し奥へ凹ませる（逆ドーム型ソケット）。
7. `Alt + H` で再表示。
8. **重要**: 目の開口部エッジループを選択し、**`Shift + E` でクリース（Crease = 1.0）** を付与。
   * さらに `Ctrl + E` $\to$ **マークシャープ（Mark Sharp）** を設定。
   * オートスムーズ 180° と組み合わせることで、サブディビジョンをかけても目の縁が丸まらず、パキッとしたアニメアイラインのエッジを維持する！

#### ステップ 2-11: 口腔ソケットの作成 [33:16〜36:00]
1. 口の開口部エッジループを `Alt + クリック` で選択。
2. 開口部に `Shift + E`（クリース）と `Ctrl + E`（マークシャープ）を設定。
3. `E` で奥へ押し出し、`S Z` で縦に広げ、`S X` で横に広げて口内空間を作成。
   * 口内部分のクリースは 0 に戻す（`Shift + E` $\to$ `-1`）。
4. `E Y` でさらに奥へ押し出し、奥端を `F` で四角面で塞ぐ。

## 2. Claude Code への実装アドバイス（Python/bmesh化の勘所）

1. **ステップ2（目の初期サークル）の入力データ**:
   * 位置: `AnimeFace/lib/common.py` の正面下絵の目中心座標（X=0.0895m付近, Z=0）。
   * 初期サークル半径: 目の下絵バウンディングボックスの短径に合わせる（半径約 0.035m）。
   * 回転: `RX = 90°`。
   * 頂点数: **必ず8**。
2. **押し出し（E+S）の自動化**:
   * `bmesh.ops.extrude_edge_only` $\to$ 法線外側へのスケール拡大（約 1.3〜1.4倍）。
3. **エッジのシャープ保持**:
   * 目の開口部エッジの `edge.crease = 1.0`
   * `edge.smooth = False`（マークシャープ相当）
4. **モディファイア順序**:
   ```python
   # 1. Mirror (Clipping=True)
   mod_mirror = obj.modifiers.new(name="Mirror", type='MIRROR')
   mod_mirror.use_clip = True

   # 2. Subdivision Surface (levels=2)
   mod_subsurf = obj.modifiers.new(name="Subsurf", type='SUBSURF')
   mod_subsurf.levels = 2
   mod_subsurf.render_levels = 2
   ```
