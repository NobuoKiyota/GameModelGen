# 髪型参考下絵（カラー）作成レポート

## 概要
Blenderでのプロシージャル髪モデリングの土台（アンダードローイング）として、確定済みの頭部・顔レンダリング（`AnimeFace/out/for_antigravity_*.png`）に完全適合する3面（正面・真横・斜め45度）のカラー参考下絵を作成・配備しました。

## 仕様と遵守状況

| 項目 | 指定条件 | 実装結果 | 判定 |
| :--- | :--- | :--- | :---: |
| **頭部形状・比率** | 添付画像（ハゲ頭）の輪郭・比率・位置を一切変更しない | 頭部・目・眉・口・首の位置・スケール完全一致（誤差<0.1px） | **PASS** |
| **画像フォーマット** | 1024×1024px、PNG | 1024×1024px PNG（3枚） | **PASS** |
| **背景色** | 既存ブループリントと同じグレー | RGB `[205, 205, 205]`（#cdcdcd）に統一 | **PASS** |
| **髪型デザイン** | ふさこ氏チュートリアル準拠（前髪非対称1房＋対称サイド＋丸い後頭部＋ツインテール） | センター非対称房＋サイド前髪＋後頭部ボリューム＋低めツインテール | **PASS** |
| **ファイル名保護** | 既存の `chibi_blueprint_*.png` を上書きしない | 新規ファイル名 `chibi_hair_ref_*.png` で保存 | **PASS** |

## モデリング設計上の要点
1. **前髪**:
   - 額中央のメイン房（左流し）は非対称パーツとして単独配置。
   - その両脇のサイド前髪および横髪は左右対称（Mirror）で配置可能。
2. **後ろ髪**:
   - 12頂点円柱（半円筒）から後頭部を丸く包む形状に適合。
3. **ツインテール**:
   - 側頭部〜後頭部の低めの位置でヘアゴムで絞り、そこからふんわりとカールして広がる構造。
