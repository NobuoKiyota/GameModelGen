## 📌 作業工程の概要と構造分析

本動画では、デフォルメキャラクターにおける「目」の制作手法を難易度・クオリティ別に3パターン解説しています。

---

### 【共通の事前準備】(00:00 - 05:54)
1. **下絵画像の配置**:
   - `Shift + A` で下絵（画像参照）を読み込み、深度を「前面」、不透明度を半透明に設定。
2. **マテリアルの分離設定**:
   - 顔に「肌_顔」マテリアルを割り当て。
   - 体に同じ肌色を割り当てる際、**必ず「新規マテリアル化（シングルユーザー化）」して「肌_ボディ」に別名保存**する。
     - *理由*: 顔に目のテクスチャを割り当てた際に、体までテクスチャが反映される事故を防ぐため。
3. **UV展開とシーム入れ**:
   - 耳の手前ライン、頭部前面、口周り、そして**目の周囲を取り囲むループ**にシームをマーク。
   - UV展開（`U` → 展開）後、後頭部や不要な島は縮小して端に寄せ、目の周りのUVアイランドを大きく配置・左右の向きを揃える。

---

### パターン 1：テクスチャペイント方式 (初級) (05:54 - 08:42)
* **概要**: 最も手軽。メッシュを弄らず、顔テクスチャの上に直接目を手描きする。
* **シェーダーノード構築**:
  - ベース肌色の画像テクスチャ ＋ アルファ0の透過ペイント用画像テクスチャを作成。
  - 「カラーミックス（Mix Color）」ノードで重ね、ペイント側のアルファを「係数（Factor）」に接続。
* **ペイント設定**:
  - テクスチャペイントモードで、上部メニューの「X対称（Symmetry X）」をONにして左右同時描画。
  - メリット：手軽、頂点数が増えない。
  - デメリット：斜め・横から見たときの立体感に欠け、テクスチャ解像度に依存する。

---

### パターン 2：素材画像貼り付け方式 (中級) (08:42 - 11:28)
* **概要**: イラストソフト等で描いた目のPNG素材を、顔のUVにマッピングして貼り付ける。
* **シェーダー構築**:
  - シェーダーミックスに目テクスチャのカラーとアルファを接続。
  - テクスチャの拡張設定を「リピート」から「延長（Clip/Extend）」に変更（タイリング防止）。
* **UVマッピング調整**:
  - UVエディタ上で目のアイランドを下絵イラストに合わせて移動・拡大縮小（`G`, `S`）。
  - UV頂点を移動（`G + Y`, `S + X`）して、まつ毛の角度や目尻のハネを調整。
* **メリット/デメリット**:
  - メリット：2D作画通りの精密なアイラインやグラデーション瞳をそのまま使える。
  - デメリット：顔の曲面で歪みやすく、瞳の奥まった立体感は出ない。

---

### パターン 3：本格立体構造（アイホールくり抜き＋独立眼球・まつ毛）(上級) (11:28 - 24:26)
* **概要**: アニメ・商業3Dモデルで標準の**「アイホールくり抜き＋奥まった凹面瞳＋ガラス風角膜＋立体まつ毛」**構造。圧倒的なクオリティと立体的な説得力を誇る。

#### 1. 顔のアイホール（眼窩）くり抜き (11:28 - 13:15)
- 顔メッシュの目の位置の面を選択し、`X` →「面を削除」で物理的に穴を開ける。
- 穴の周囲のエッジ・頂点を下絵の白目ラインに合わせて `G + X`, `G + Z` で成形。

#### 2. 白目（眼球ソケット奥壁）の作成 (16:16 - 17:00)
- 開口した目のフチのエッジ（4辺）を `Alt + クリック` で選択。
- `Shift + D` で複製 → `P` で「選択を分離」（別オブジェクト化）。
- 分離した白目メッシュの全選択から `E + Y` で**奥（頭の内側方向）へ押し出し**、`F` で面を貼って塞ぐ。
- スムーズシェードを適用（これで穴の奥に白い眼窩底ができる）。

#### 3. 瞳（凹み虹彩）と角膜ガラスの作成 (13:15 - 16:16)
- `Shift + A` で「UV球」を追加、`R + X + 90` で正面に向ける。
- 前面の頂点群を `Ctrl + Num+` で拡大選択し、`Shift + D` で複製 → `P` で分離。
  - **片方（角膜/レンズ）**: プリンシプルBSDFの伝播（Transmission）やグラスBSDFを設定し、透明な「外蓋ガラス」にする。
  - **もう片方（虹彩/Iris）**: プロポーショナル編集をONにして中心を **`G + Y` で奥へ凹ませる（逆ドーム型）**。
    - *理由*: アニメ・フィギュア特有の「どこから見ても視線が合う（追従する）奥まった瞳」を再現するため。
- 瞳のテクスチャを描き込み、レンズと瞳をハの字（`R + Z`）で眼窩の奥に配置。

#### 4. ハイライト（実照明映り込み）(17:28 - 17:36)
- 目の斜め前に「ポイントライト」を配置し、透明角膜レンズに本物のリアルな光条を反射させる。

#### 5. 3Dまつ毛（アイライン）のモデリング (17:36 - 22:15)
- `Shift + A` で「平面」を追加し、`R + X + 90` で立てる。
- `Ctrl + R` で複数ループカットを入れ、プロポーショナル編集で目のアーチに沿って曲げる。
- `E + Y` で厚みを押し出し、`Alt + S` でふっくらさせる。
- まつ毛上部の面から `E`（押し出し）＋ `S`（縮小）で目尻のハネや毛束を複数本生やす。
- 顔の曲面に沿うように `G + Y` で密着させ、ミラーモディファイアで左右対称化。

#### 6. 立体眉毛のモデリング (22:56 - 24:26)
- 低ポリゴンUV球（17×10）を追加、`R + Y + 90` で横倒し。
- プロポーショナル編集の「シャープ」を使い、眉尻をキュッと尖らせる。
- `S + Y` で平たく潰し、顔の球面に沿わせて `G + Y` でカーブをつけ、ミラー化。
