# 🤝 AIコラボレーションプロトコル（Claude Code × Antigravity）

## 背景・目的
ユーザー(kiyot)は、会社・自宅を問わず複数プロジェクトで **Claude Code** と **Antigravity(Gemini)** を
常時併用し、それぞれの得意分野を分担させたいと考えている。毎回ユーザーが手動でプロンプトや結果を
コピー＆ペーストして橋渡しするのは非効率なため、このファイル一式が「共有の伝言板」として機能する。

## 制約（重要・必ず前提とすること）
- Claude Code と Antigravity の間に、リアルタイムで直接呼び合うAPI/プロトコルは存在しない。
- 両ツールは同じローカルのGitリポジトリ（ファイルシステム）を共有しているのみ。
- したがって連携は **非同期**（相手がいつ読むか分からない）ものとして設計する。

## 得意分野の分担（目安。固定ルールではない）
- **Claude Code**: コード実装、Blender/Pythonの実行・検証、テスト実行、反復デバッグ、
  ファイルの直接編集とヘッドレスBlenderでの動作確認
- **Antigravity (Gemini)**: 動画・音声の文字起こしと長尺コンテンツの要約、リサーチ、
  長文コンテキストの整理・構造化

どちらが何を担当するかはユーザーの指示次第で変わる。重要なのは
「相手が今どこまで知っていて、何を頼まれているか」を共有ファイル経由で追えるようにすることそのもの。

## 共有ログ: `.agents/shared_log.md`
- 追記専用（append-only）。両ツールがここを読み書きする。
- **セッション開始時**: このリポジトリで作業を始める前に、`.agents/shared_log.md` の末尾（直近のエントリ）を必ず確認する。
- **作業の節目・セッション終了時**: 下記フォーマットで追記する。特に「相手への申し送り」がある場合は必ず書く。

### エントリのフォーマット
```
## [YYYY-MM-DD HH:MM] <ツール名> — <一言タイトル>
**状況**: 何をしていたか（1〜2行）
**分かったこと/やったこと**: 要点のみ。詳細は別ファイルに書いてパスをリンクする
**相手への申し送り**: 相手のツールに確認・実施してほしいこと（無ければ省略可）
**参照**: 関連ファイルパス（あれば）
```

## 運用ルール
1. **コードの変更履歴は `git log` / `git status` を正とする**。shared_log.md にコード差分そのものは書かない
   （ユーザーのグローバル方針: 手動の引き継ぎドキュメントよりgit履歴が優先）。
2. shared_log.md は「会話・調査結果・申し送り」専用。動画の文字起こし全文など長い内容は
   `.agents/handoffs/<日付>_<題名>.md` に保存し、shared_log.md にはパスだけ書く。
3. 簡潔に。1エントリは長くても20〜30行程度に収める。
4. **ユーザー本人の承認が必要な意思決定は、このログで済ませず必ずユーザーに確認する**。
   このログは2つのAI間の申し送り用であり、ユーザーの承認を代替するものではない。

## 他プロジェクトへの展開
同じ枠組みを他のリポジトリでも使う場合は、`.agents/` ディレクトリ一式（このファイルと
`shared_log.md` のテンプレート）をコピーして流用すればよい。
