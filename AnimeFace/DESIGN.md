# AnimeFace 設計書（2026-09-21 新規設計）

目的: 2頭身アニメ顔を、目から作る王道ポリゴンモデリングで作る。
既存の `.blend` / `blender_addons/chibi_face_studio` / ルート直下の旧スクリプトは**参考のみ**。このフォルダ内で完結させ、旧ファイルは変更しない。

## 1. 進め方の原則
1. **1ステップ＝1スクリプト＝1つの `.blend`。** `steps/sNN_*.py` が `out/face_s(NN-1).blend` を読み `out/face_sNN.blend` を書く。既存ファイルは上書きしない
2. **モディファイアは Apply しない**（Mirror / Subsurf はスタックに残す）
3. **各スクリプトは数値ゲートを持つ。** 1つでも FAIL なら終了コード1で止まり、次のステップに進まない（`lib/common.py` の `Gates`）
4. **頂点を動かす前にトポロジー（頂点数・ループ数）を決めて記録する。** 足りなければ先にループカット
5. **提出物は事実のみ:** ケージワイヤー画像＋ソリッド画像＋頂点数・モディファイア構成＋ゲート結果。「完成」「〇点」は書かない
6. 美的判断（かわいさ・張り）と各ステップの承認は**ユーザー**。AIは手順・座標・数値検証を担当

## 2. 座標系・スケール（`lib/common.py` と一致させる）
| 項目 | 値 |
| :--- | :--- |
| 単位 | メートル。**1px = 0.0007 m**（下絵1辺1024px = 0.7168 m） |
| 顔の向き | **-Y 向き**（Blender 標準。正面ビューは +Y 方向を見る） |
| X=0 / Y=0 | 下絵の中心列（col 512）。顔の正中線 |
| Z=0 | **瞳の中心行（row 518.5）** ＝目の高さ。頭頂 Z≈+0.29、顎 Z≈-0.22 |
| 正面 px→3D | `X=(u-512)*K`, `Z=(518.5-v)*K` |
| 側面 px→3D | `Y=-(u-512)*K`（顔が画面右向き＝-Y）, `Z=(518.5-v)*K` |
| カメラ | `CAM_front / CAM_a45 / CAM_side`。オルソ、`ortho_scale=0.7168`、下絵とピクセル一致 |

## 3. 下絵の使い分け（測定に基づく決定）
`textures/human/chibi_blueprint_{front,45deg,side}.png`（1024²）を測定した結果:

| 部位 | 正面 | 45° | 側面 |
| :--- | ---: | ---: | ---: |
| 頭頂 | 104 | 104 | 104 |
| 眉の中心 | 393 | 402 | 394 |
| 瞳の中心 | 519 | 529 | 518 |
| 瞳の縦の長さ | 55 | 62 | 46 |
| 鼻先 | 618（点の中心。**鼻先と鼻下の中間**） | 629 | 591（先端）／鼻下 645 |
| 口 | 713 | 約705 | 約680 |
| 顎の底 | 829 | 約795 | 約818 |
| 下まぶたの最下点 | 589 | — | 579（同じ位置で約15px食い違う。**正面を正とする**） |
| 口の線の中心の行 | 723 | 709 | 約677（視点が横に近いほど高い。S03 は正面を採用、人間が補正） |
| 口の前後位置 Y(m) | — | 約 -0.163 | -0.204（側面の輪郭。45°の口は約40mm後ろに描かれている） |

- **高さの正は「正面＋側面」。** 目（眉・瞳）はこの2枚が1px以内で一致
- **45° は水平方向の形（頬・眼窩の張り出し）の参考のみ。** 高さ・目の大きさは45°から取らない（約10px下、瞳が約13%大きい）
- **鼻・口・顎は正面と側面で最大約30px食い違う。** 該当ステップに来た時にユーザーが基準を決める
- 画像を生成AIに再生成させて揃えることはしない（収束しないため）。揃えるなら測定スクリプトによる縦方向の補正で行う

## 5. ファイル構成
```
AnimeFace/
  DESIGN.md   この設計書
  STATE.md    現在の工程・ステップ・直近の合否（毎回更新）
  lib/common.py         定数・座標変換・ゲート
  steps/sNN_*.py        ステップごとの実行スクリプト
  out/                  生成 .blend / レポートJSON / 検証画像
```
実行: `blender --background --factory-startup --python steps/sNN_xxx.py`（Blender 5.2）
